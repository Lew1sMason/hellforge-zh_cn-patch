# 启动与共享错误 批次复核（launch-errors）

只覆盖 Windows 启动与共享错误。设置/安装、档案/模组、控制台由其他会话负责，本文件不处理也不合并其产出。机器可读结果在同目录 `launch-errors.csv`。

## 1 筛选口径

起点是主表已处理的 76 条与 `inventory/scope-inventory.csv`。取台账中模块为“启动”“错误”且状态为待译的行，共 68 条；其中 23 条进入本批，45 条按边界排除。

用户可见的判据是写入提示或状态控件的方法，包括 `Start`、`StartPreflight`、`ShowEarlyFailure`、`RequestStop`、`ShowLeftoverProcesses`、`ShowFailed`、`ShowState`、`UpdateSyncStatus`。内部日志的判据是日志行或调试输出，例如 `ProxyClosedLine` 生成的记录、`Profile: `、`Launch options: ` 一类拼接前缀，这些只进日志，不进界面。

## 4 PD-004 拼接链复核

只依据现有字符串与 IL 顺序复核，不改主表。以下位置均为 `MainWindow.UpdateSyncStatus`。

| us | 内容（repr） | IL 偏移 | 性质 |
|---|---|---|---|
| 3249 | `'Last synced '` | 91 | 显示片段，成功分支前缀 |
| 3275 | `'g'` | 136 | 时间格式说明符，不进显示文本 |
| 3279 | `'at an unknown time'` | 155、368 | 显示片段，时间缺失时替代日期 |
| 3317 | `': '` | 172、385 | 已锁定共享分隔符，ASCII 冒号加空格 |
| 3323 | `'N0'` | 190、265、403 | 数字格式说明符，不进显示文本 |
| 3329 | `' items, '` | 202 | 显示片段，前导空格 |
| 3347 | `'progression captured.'` | 246 | 显示片段，成功分支 |
| 3391 | `' XP.'` | 277 | 显示片段，前导空格加 `XP.` |
| 3401 | `'Last sync failed '` | 304 | 已锁定，失败分支前缀 |
| 3437 | `' items, no progression. Sync again to get your level, unlocks and ship.'` | 415 | 显示片段，失败分支 |

`g` 与 `N0` 分别作为日期、数字的格式参数参与运行期取值，屏幕上出现的是格式化后的时间与数量，不是这两个字符串本身。显示文本里不写 `N0`，也不写 `{0}`。

按 IL 顺序复原的链如下，`{时间}`、`{数量}`、`{经验}` 代表运行期值。成功尾部为二选一，不会同时出现。

成功且经验值存在：`Last synced ` + `{时间}` + `: ` + `{数量}` + ` items, ` + `{经验}` + ` XP.`

成功且经验值缺失：`Last synced ` + `{时间}` + `: ` + `{数量}` + ` items, ` + `progression captured.`

时间缺失时，上两条中的 `{时间}` 替换为 `at an unknown time`。

失败：`Last sync failed ` + `{时间}` + `: ` + `{数量}` + ` items, no progression. Sync again to get your level, unlocks and ship.`

对应中文示例，仅为语序演示，未写入主表。

成功且经验值存在：`上次同步于 {时间}: {数量} 项，{经验} XP。`

成功且经验值缺失：`上次同步于 {时间}: {数量} 项，已捕获进度。`

失败：`上次同步失败 {时间}: {数量} 项，无进度。再次同步以获取等级、解锁项与舰船。`

需要说明的三点。失败分支的前缀已锁定为“上次同步失败 ”，不能为通顺改写。共享分隔符 `': '` 已锁定，成功与失败两条链都会出现 ASCII 冒号，中文里不加空格。`' XP.'` 前导空格用于与运行期数值隔开，若保留 XP 则中文片段同样以空格开头。

批次 3 更正。复核确认 `g` 与 `N0` 只是格式参数，不进入显示文本；`': '` 本身已带 ASCII 空格。

批次 5 更正。负责人直接检查 `UpdateSyncStatus` 的 IL 234、244、251、294 与目标分支，成功尾部是二选一，不存在“进度说明加经验值”的串联。上文已按二选一改写。仍未定的只有中文语序、失败链尾句压缩与 XP 译名，见 ERR-04 至 ERR-06 及 PD-004。

## 5 需决定的问题

ERR-01 设置页标签引用。HF-21926、HF-22079 的提示里写有 `Settings > Multiplayer`。候选 A 译“设置 > 多人游戏”，与设置模块保持同一标签；候选 B 改写成“在设置中开启多人游戏”，避开标签名。建议 A，待设置模块标签定稿后统一；若设置会话采用别的译名，这两条要跟着改。

ERR-02 Experiments 分区名。HF-23578 提到 `Experiments > Local PlayFab`。候选 A “实验功能”，候选 B 保留 `Experiments` 英文，候选 C 改写成不带路径的提示。建议 B 或 C，因为该分区在设置页的具体中文名未定，直接翻译容易与设置页不一致。

ERR-03 中文片段间的前导空格。HF-22853 原文为 `' is missing.'`，与 `Local backend` 拼接后是“Local backend 缺失”。候选 A 译为“ 缺失。”保留空格，界面显示“本地后端 缺失。”；候选 B 译为“缺失。”，显示“本地后端缺失。”。建议 B，中文与中文之间不加空格；本条暂留空，等确认后一次写入。

ERR-04 成功链的中文语序。成功尾部二选一，需分别成句。候选 A 经验值存在时“上次同步于 {时间}: {数量} 项，{经验} XP。”，缺失时“上次同步于 {时间}: {数量} 项，已捕获进度。”；候选 B 把数量提前：“上次同步：{数量} 项，{时间}，…”。候选 B 会破坏运行期顺序，不可行；A 可行但时间缺失时出现“上次同步于 未知时间”。建议采用 A，时间缺失时把 `at an unknown time` 译为“未知时间”，并接受该句略生硬。

ERR-05 失败链尾句。`Sync again to get your level, unlocks and ship.` 候选 A “再次同步以获取等级、解锁项与舰船。”；候选 B “再次同步即可取回等级、解锁内容与舰船。”。建议 A，动词短语与按钮风格一致；“ship”取“舰船”与档案页术语一致。

ERR-06 数量单位与千分位。`N0` 会输出带千分位的数字。候选 A 保留千分位并用量词“项”；候选 B 去掉千分位，改为“条”。建议 A，与 .NET 运行期输出一致，避免另行格式化；`XP` 是否保留英文并到术语表统一，若改为“经验值”，` XP.` 需同步改动。

PD-006（Session runner 的界面位置）译名已定，仅待实机验证，不再要求委托方裁定，不在本表编号。构建可用后在设置页路径区核对显示位置即可。
